# Документация

## Описание проекта
В этом проекте реализованы функции нахождения площади и периметра для таких фигур как:
1. Круг
2. Прямоугольник
3. Квадрат
4. Треугольник

## Описание Функций

### circle.py

#### area()

- Принимает на вход радиус круга, возвращает площадь круга.

- Пример вызова:

```python
area(2)
```

#### perimeter()

- Принимает на вход радиус окружности, возвращает её периметр.

Пример вызова:

```python
perimeter(3)
```

### rectangle.py

#### area()

- Возвращает площадь прямоугольника.

- Принимаемые значения:

    a (int): первая сторона прямоугольника
    b (int): вторая сторона прямоугольника

- Возвращаемое значение:

    (int): площадь прямоугольника

- Пример вызова функции:

```python
area(6, 7)
```

#### perimeter()

- Возвращает периметр прямоугольника.

- Принимаемые значения:

    a (int): первая сторона прямоугольника
    b (int): вторая сторона прямоугольника

- Возвращаемое значение:

    (int): периметр прямоугольника

- Пример вызова функции:

```python
perimeter(6, 7)
```

### square.py

#### area()

- Принимает на вход сторону квадрата, возвращает площадь квадрата.

- Пример вызова:

```python
area(3)
```

#### perimeter()

- Принимает на вход сторону квадрата, возвращает периметр квадрата.

- Пример вызова:

```python
perimeter(3)
```

### triangle.py

#### area()

- Возвращает площадь треугольника.

- Принимаемые значения:

    a (int): основание треугольника
    h (int): высота треугольника

- Возвращаемое значение:

    (int): площадь треугольника

- Пример вызова функции:

```python
area(6, 7)
```

#### perimeter()

- Возвращает периметр треугольника.

- Принимаемые значения:

    a (int): первая сторона треугольника
    b (int): вторая сторона треугольника
    c (int): третья сторона треугольника

- Возвращаемое значение:

    (int): периметр треугольника

- Пример вызова функции:

```python
perimeter(6, 7, 8)
```
